The table is generated from [`apps/docs/src/data/bench-rn-latest.json`](https://github.com/nwnichols02/melon/blob/main/apps/docs/src/data/bench-rn-latest.json). To refresh after a new device run:

1. In `apps/playground-rn-dev`, open **Benchmarks** and run **jsi-sync + Watermelon** at **10k** (or **1k** for smoke).
2. Tap **Share JSON report** and merge `melonVsWdb` (and optionally `report` for jsi vs turbo) plus `generatedAt` / `device` into `bench-rn-latest.json`.
3. Commit the updated JSON with your PR so the docs site picks up the new timings.

Same scenarios as the Node harness: row insert, batch insert, filtered query, count, and find-by-id. Ratio for Melon vs WDB is `melonMs / watermelonMs` (&lt; 1 means Melon faster).
