title: Alpha support policy
description: What to expect from Melon alpha releases.
---

Melon alpha releases are intended for evaluation, early adopters, and contributors. They are published under the `alpha` dist-tag (for example, `@melon-db/db@alpha`).

## Stability and breaking changes

- The alpha series is **0.x**. Breaking changes may occur between alpha versions.
- Release notes in `CHANGELOG.md` describe any breaking changes and known limitations.
- If you are building on Melon alpha, pin exact versions rather than using broad semver ranges.

## Support

- There is **no production SLA** for alpha releases.
- Bug reports and feature requests should be filed on GitHub using the issue templates.
- Security vulnerabilities should be reported via the process in `SECURITY.md`.

## Version support

- Only the latest alpha is supported for fixes.
- Older alpha versions may receive no patches; upgrade to the current alpha to pick up fixes.
