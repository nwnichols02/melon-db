Melon-db is an offline-first local database for React Native and TypeScript — a modern successor to WatermelonDB.

## Install

### Install from npm (alpha)

Melon-db publishes alpha builds under the `alpha` dist-tag.

```bash
npm install @melon-db/db@alpha @melon-db/db-sqlite@alpha @melon-db/db-react@alpha
```

Or with Bun:

```bash
bun add @melon-db/db@alpha @melon-db/db-sqlite@alpha @melon-db/db-react@alpha
```

For Node/Bun SQLite, `@melon-db/db-sqlite` uses `bun:sqlite` by default. For React Native native JSI, install `@melon-db/db-sqlite-native@alpha` and follow the RN walkthrough.

### Install from this monorepo

From the monorepo root:

```bash
bun install
bun test
```

## In-memory quick start

```ts
import { createDatabase, createInMemoryAdapter, createMelonSchema } from '@melon-db/db';

const schema = createMelonSchema({
  version: 1,
  collections: {
    tasks: {
      name: 'tasks',
      primaryKey: 'id',
      fields: { id: { kind: 'string' }, title: { kind: 'string' } },
    },
  },
});

const db = createDatabase({ schema, adapter: createInMemoryAdapter() });

await db.write(async (tx) => {
  await tx.collection('tasks').insert({ id: '1', title: 'Hello' });
});
```

Follow the [Local-first walkthrough](/docs/walkthroughs/local-first) for a full checklist.

```bash
bun run dev:web
```

Or use the [CRUD playground](/docs/playgrounds/crud) in the docs site. See [Web walkthrough](/docs/walkthroughs/web-local).

## React Native / Expo

**Expo Go** (default):

```bash
bun run dev:rn
```

See [React Native (Expo) walkthrough](/docs/walkthroughs/react-native-expo).

**Development build** (JSI native SQLite):

```bash
bun run dev:rn:dev
bun run dev:rn:dev:start
```

See [React Native (JSI) walkthrough](/docs/walkthroughs/react-native-jsi).
