## v1 limitations

- All mutations must run inside `db.write()`.
- SQLite migrations: add-column and create-table only.
- Relation includes: `belongsTo` only (no `hasMany` in queries).
- Native SQLite `observeQuery` triggers not implemented (engine change emitter used).
