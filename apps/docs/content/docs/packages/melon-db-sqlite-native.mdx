**Status:** Shipped (iOS TurboModule + Android bridge) · **Expo Go:** Not supported

Native SQLite module used by [`@melon/db-sqlite/rn`](/docs/packages/melon-db-sqlite). For Expo Go, use [`@melon/db-sqlite/expo`](/docs/packages/melon-db-sqlite) instead.

## Platform support

| Platform | Binding | Status |
|----------|---------|--------|
| iOS (dev build) | TurboModule (`MelonSQLiteSpec` codegen) | Supported |
| Android (dev build) | Legacy bridge | Supported |
| Expo Go | N/A | Not available |

## Limitations

- Async TurboModule/bridge methods only (no sync C++ JSI on the JS thread).
- **BLOB / `bytes` fields** are not round-tripped (returned as `null`).
- No native `observeQuery` triggers.
- Android TurboModule parity deferred to Phase 23.

## Setup

- **Expo Go:** [`apps/playground-rn`](/docs/getting-started) — `bun run dev:rn`
- **Development build (iOS):** `bun run dev:rn:dev` then `bun run dev:rn:dev:start` — expect `native turbo (ios)` badge
- **Development build (Android):** `bun run dev:rn:dev:android` then start Metro — expect `native bridge (android)` badge

Pass `basePath` (e.g. `expo-file-system` `documentDirectory`) when using a relative `filename`.

After changing [`NativeMelonSQLite.ts`](https://github.com/melon/melon/blob/main/packages/melon-db-sqlite-native/src/NativeMelonSQLite.ts), regenerate codegen and run `expo prebuild --clean` in `apps/playground-rn-dev`. See the [package README](https://github.com/melon/melon/blob/main/packages/melon-db-sqlite-native/README.md).
