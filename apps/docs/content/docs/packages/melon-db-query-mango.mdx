**Status:** Shipped (documented subset) · **Depends on:** `@melon/db` · **API:** [Reference](/docs/api/melon-db-query-mango)

Serializable CouchDB/RxDB-style selectors for configs, tests, and devtools.

## Install (alpha)

```bash
npm install @melon/db-query-mango@alpha
```

Or with Bun:

```bash
bun add @melon/db-query-mango@alpha
```

## Example

```ts
import { createMangoCompiler } from '@melon/db-query-mango';

const compiler = createMangoCompiler();
const prepared = compiler.compile(
  {
    selector: { status: 'open', priority: { $gte: 2 } },
    sort: [{ updatedAt: 'desc' }],
    limit: 20,
  },
  schema,
);

const rows = await db.collection('tasks').query(prepared).fetch();
```

Unsupported Mango operators fail at compile time with actionable errors.
