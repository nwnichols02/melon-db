**Status:** Shipped (subset) · **Depends on:** `@melon-db/db` · **API:** [Reference](/docs/api/melon-db-prisma)

Schema/codegen layer — **not** the Prisma remote engine. Executes on `MelonDatabase` locally.

## Install (alpha)

```bash
npm install @melon-db/db-prisma@alpha
```

Or with Bun:

```bash
bun add @melon-db/db-prisma@alpha
```

## Client

```ts
import { createPrismaLikeClient } from '@melon-db/db-prisma';

const client = createPrismaLikeClient(db);
await client.tasks.findMany({ where: { status: 'open' } });
```

## CLI

```bash
bun run melon-prisma generate --schema=./schema.prisma --out=./generated/melon
```

Supports SQLite datasource, scalar fields, relations, and a constrained `where` / `orderBy` subset.
