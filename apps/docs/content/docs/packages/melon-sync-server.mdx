**Status:** Shipped · **Depends on:** `@melon/sync`, `@melon/db` · **API:** [Reference](/docs/api/melon-sync-server)

```bash
bun run sync-server
bun run sync-server:postgres
```

| Method | Path |
|--------|------|
| POST | `/sync/pull` |
| POST | `/sync/push` |

Postgres backend uses Bun SQL with `sync_meta`, `sync_tasks`, and tombstone tables. SQL migrations live in `packages/melon-sync-server/sql/`.
