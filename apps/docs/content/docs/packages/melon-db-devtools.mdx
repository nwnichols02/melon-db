**Status:** Shipped · **Depends on:** `@melon-db/db` · **API:** [Reference](/docs/api/melon-db-devtools)

Zero-cost when disabled via `createNoopDevtoolsBridge()`.

## Install (alpha)

```bash
npm install @melon-db/db-devtools@alpha
```

Or with Bun:

```bash
bun add @melon-db/db-devtools@alpha
```

```ts
import { createReactiveDevtoolsBridge } from '@melon-db/db-devtools';
import { MelonDevtoolsPanel, MelonDevtoolsProvider } from '@melon-db/db-devtools/react';

const devtools = createReactiveDevtoolsBridge();
const db = createDatabase({ schema, adapter, devtools });
```

Try the [CRUD playground](/docs/playgrounds/crud) with the panel embedded.
