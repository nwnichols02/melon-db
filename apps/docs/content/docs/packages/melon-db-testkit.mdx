**Status:** Shipped · **Depends on:** `@melon-db/db` · **API:** [Reference](/docs/api/melon-db-testkit)

Deterministic in-memory testing without native SQLite.

## Install (alpha)

```bash
npm install @melon-db/db-testkit@alpha
```

Or with Bun:

```bash
bun add @melon-db/db-testkit@alpha
```

```ts
import { withTestDatabase } from '@melon-db/db-testkit';

await withTestDatabase(schema, async (db) => {
  await db.write(async (tx) => {
    await tx.collection('tasks').insert({ id: '1', title: 'Test' });
  });
});
```

Re-exports in-memory adapter helpers aligned with `@melon-db/db` test patterns.
