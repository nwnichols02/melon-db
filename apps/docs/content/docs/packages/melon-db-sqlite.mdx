title: "@melon/db-sqlite"

**Status:** Shipped · **Depends on:** `@melon/db` · **API:** [Reference](/docs/api/melon-db-sqlite)

Compiles `QueryAst` to parameterized SQL and implements `StorageAdapter` for production local storage.

## Bun / Node

```ts
import { createSqliteAdapter } from '@melon/db-sqlite';

const adapter = createSqliteAdapter({ filename: 'app.db' });
```

## Expo

```ts
import { createExpoSqliteAdapter } from '@melon/db-sqlite/expo';
```

## Node (better-sqlite3)

```ts
import { createNodeSqliteAdapter } from '@melon/db-sqlite/node';
```

## Benchmarks

```bash
bun run bench
```
