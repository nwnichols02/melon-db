**Status:** Shipped · **Depends on:** `@melon/db` · **API:** [Reference](/docs/api/melon-db-sqlite)

Compiles `QueryAst` to parameterized SQL and implements `StorageAdapter` for production local storage. Includes **predicate-aware `observeQuery`** (Phase 27): reactive queries re-fetch only when a write can affect their WHERE clause.

## Install (alpha)

```bash
npm install @melon/db-sqlite@alpha
```

Or with Bun:

```bash
bun add @melon/db-sqlite@alpha
```

## Bun / Node

```ts
import { createSqliteAdapter } from '@melon/db-sqlite';

const adapter = createSqliteAdapter({ filename: 'app.db' });
```

## React Native: Expo Go vs development build

| Path | Import | Expo Go |
|------|--------|---------|
| **Default** | `@melon/db-sqlite/expo` + `expo-sqlite` | Yes |
| **Native** | `@melon/db-sqlite/rn` + `@melon/db-sqlite-native` | No — requires `expo prebuild` + dev build (iOS + Android) |

### Expo Go

```ts
import { createExpoSqliteAdapter } from '@melon/db-sqlite/expo';
import * as SQLite from 'expo-sqlite';

const database = await SQLite.openDatabaseAsync('app.db');
const adapter = createExpoSqliteAdapter({ database });
```

### Native (development build, iOS + Android)

```ts
import { Paths } from 'expo-file-system';
import { createJsiSqliteAdapter, isJsiSqliteAvailable } from '@melon/db-sqlite/rn';

if (!isJsiSqliteAvailable()) {
  throw new Error('Use expo-sqlite or run a development build');
}

const adapter = createJsiSqliteAdapter({
  filename: 'app.db',
  basePath: Paths.document.uri.replace(/^file:\/\//, ''),
});
```

See [`@melon/db-sqlite-native`](/docs/packages/melon-db-sqlite-native) for native setup.
