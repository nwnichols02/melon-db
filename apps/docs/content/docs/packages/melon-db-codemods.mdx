title: "@melon/db-codemods"

---

**Status:** Shipped (common patterns) · **Depends on:** `@melon/db` types · **API:** [Reference](/docs/api/melon-db-codemods)

```bash
bun run melon-codemod migrate-queries --path=./src
bun run melon-codemod migrate-writes --path=./src
bun run melon-codemod migrate-react --path=./src
```

Runtime `translateWatermelonQuery` converts serializable `Q` clauses to `QueryAst`. Joins (`Q.on`) and decorator schema codemods are **manual / deferred**.

See [Migration](/docs/migration).
