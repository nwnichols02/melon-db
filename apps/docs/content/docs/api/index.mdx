API documentation is generated from each package's `src/index.ts` with **TypeDoc** and enriched with **Fumadocs TypeScript** type tables on [package guide](/docs/packages/melon-db) pages.

Each package index is titled with its **npm scope** (e.g. `@melon/db`), not a generic "Melon API".

## Regenerate

From the monorepo root:

```bash
bun run --filter docs docs:api
```
